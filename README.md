# PawCare 🐾

Evcil hayvan takip ve yönetim uygulaması. UIKit + Firebase ile geliştirildi.

## Özellikler

- Giriş / Kayıt (Firebase Auth)
- Evcil hayvan ekleme, düzenleme, silme (Firestore)
- Hayvan fotoğrafı yükleme (base64, Firebase Storage gerektirmez)
- AI veteriner sohbeti
- Ana ekran özeti ve hızlı erişim

## Teknolojiler

- Swift / UIKit (programmatic, Storyboard yok)
- SnapKit
- Firebase Auth & Firestore

## Kurulum

1. Repoyu klonla
2. Kendi Firebase projenden `GoogleService-Info.plist` dosyasını `FireBaseProject/Resources/` klasörüne ekle
3. Xcode'da aç, çalıştır
